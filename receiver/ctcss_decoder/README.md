CTCSS tone decoder for OpenWebRX+. It analyzes the receiver audio and displays the detected tone, signal level, detection quality, and lock state.

Features:
- Detects 40 standard CTCSS tones
- Live tone indication and stable **LOCK**
- **AUTO SQL** with manual threshold option
- Remembers the last confirmed tone (**LAST**)
- Compact, movable on-screen panel

The decoder runs in the browser and does not require a server-side component.
